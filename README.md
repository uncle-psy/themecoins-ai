# The Solana System

The production site for [themecoins.ai](https://themecoins.ai/): a graph-native atlas of Solana's protocol, economy, institutions, culture, risks, and repair.

The site is dependency-free static HTML, CSS, and JavaScript. It contains 105 concept nodes with independently generated artwork, 40 constellations, 72 typed edges, 52 Mapshifts, structured readings, games, curriculum, and a source-aware evidence view.

## Local preview

Run any static file server in this directory and open its root URL.

## Deployment

The repository is deployed through Vercel. Production configuration lives in `vercel.json`.
